## C5 — жизненный цикл

На исходном адаптере замена только `iface.cmd` дала повтор seq 3,
замена только `iface.fmt` потеряла форматирующую запись, а оборачивание
внешнего хука вокруг прежнего cmd дало лишнее событие. В реальном
INSTEAD выяснилось, что STEAD может сериализовать глобальную таблицу
адаптера. В пробе F9 восстановил её из игрового слота и вытеснил актуальные
функции. Добавлен штатный хук `save`, исключающий таблицу из игрового слота.

Единое состояние хранит счётчик, путь, карту объектов и активные обёртки.
Отдельная проверка cmd и fmt восстанавливает только заменённый хук. Из цепочки
пишет только активная обёртка. Она определяет своё право писать перед
вызовом оригинала и берёт актуальный снимок после него. Файл закрывается
после каждой записи. В свежей Lua VM начальное значение восстанавливается из
TSV. Независимый TSV начинает с 1, совместная запись нескольких процессов
в один файл не входит в контракт.

Все 11 тестов стенда завершились с кодом 0. Проверены неизменные функции,
замена cmd, fmt и обеих групп, вложенная обёртка, смена объектов, 64
переинициализации, замена хуков внутри текущего вызова, сброс глобального
состояния, append и новый путь. Стенд подсчитывает открытые дескрипторы и
проверяет заголовок, порядок и точное число строк. В облаке стенд выполнен
через локальный C-лаунчер с установленной библиотекой LuaJIT.
