## Что исправлено

1. **`pick_instead_state_record`:**
   - save: требуется свежая запись команды `save`; любая свежая `scene` с другим
     `semantic_state` (UUID, экран, порция, переменные) отклоняется — **даже если `rendered` пуст**.
     Это закрывает контрпример Ревьюера (seq10 page A portion1 → seq11 page B portion0 empty).
   - load: требуется сцена с текстом на/после записи `load` (реальная трасса INSTEAD совмещает
     команду и сцену в одной записи); при наличии `expect` проверяются страница, порция,
     переменные. Старый trace доказательством не считается.
   - отсутствие свежих записей — ошибка, а не доказательство.
2. **Переинициализация трассы** определяется по префиксу записей и укорочению, а не только
   `max_seq < cursor`: перезаписанная трасса, догнавшая старый seq, тоже распознаётся.
3. **Клавиши INSTEAD 3.5.2** по `src/game.c`: F2/F3 — меню слотов, F5 — look, F8 — quick save,
   F9 — quick load; F5/F6 больше не классифицируются как save/load.
4. **Жизненный цикл адаптера:** обёрнутые функции хранятся в слабой таблице; после перезагрузки
   `main.lua` новая `iface.cmd` оборачивается, старая — нет (нет двойной записи).
5. **B5/B6:** новый `check_instead_save_load.py` — перезапуск INSTEAD с тем же appdata и
   повторные циклы save/load в одном процессе; раннер получил `--instead-seed-appdata`.
