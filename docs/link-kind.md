# Вид ссылки: переход (ways) или выбор после текста

То же, что в NLB (`docs/link-kind.md` там — с разбором ссылок тестовых книг и причинами). На
страницах STANDARD ссылка — либо переход между локациями (ways над текстом), либо выбор после
текста (xact, `Choice::inlineLink`):

1. реплики (текст начинается с `-`, `"` или `'`) и «Далее» — всегда выборы;
2. остальное — по виду ссылки: файл `kind` в каталоге ссылки (`WAY` / `CHOICE`, нет файла —
   `AUTO`), `Link::getKind`;
3. `AUTO` — по настройке книги: файл `choicelnk` (`true` — выборы, по умолчанию — переходы),
   `NonLinearBook::isChoiceLinks`; внутренние модули наследуют значение родителя (и могут
   переопределить своим файлом), внешние — выборы, если так настроены книга-родитель или сам модуль. Ссылки, созданные на лету
   (вход в модуль, возврат, автоссылки), — `AUTO`; ссылки модульной страницы на страницах модуля
   (MPL) — с видом исходной ссылки.

Решение — в `PlayerEngine::view()`; так же решает экспорт в INSTEAD (`ExportManager.isInlineLink`).
Старые книги без этих файлов не меняются. «Фронтир» с `choicelnk` выглядит как в прежнем экспорте,
где ways не было вовсе.
