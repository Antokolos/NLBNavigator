# Снимок состояния для тестов: `nlb_sdl --state-log`

Для дифференциальных тестов с INSTEAD (`tests/differential`, ветка `ci/nlb-sdl-wolfman`) и
других автоматических проверок nlb_sdl может писать состояние игры после каждой команды
сценария `--script`. Снимок только читает состояние: ничего не обновляет и не перерисовывает,
по умолчанию выключен.

```
nlb_sdl <книга> vn --script route.script --state-log state.jsonl --state-vars wolfiness,hp
```

- `--state-log <файл>` — JSON Lines: одна строка до первой команды (`index` = 0) и по одной
  после каждой команды сценария (пустые строки и комментарии `#` не считаются);
- `--state-vars <имена через запятую>` — переменные книги для снимка (имена как в книге, без
  `_` экспорта INSTEAD); `*` — все переменные, включая служебные. Без параметра переменных в
  снимке нет. Несуществующие имена пропускаются.

## Запись (schema 1)

| поле | что это |
|---|---|
| `schema` | версия формата, сейчас 1 |
| `index` | номер команды сценария, с 1; 0 — состояние до первой команды |
| `command` | строка команды как в сценарии |
| `ok` | команда выполнена (то же, что отсутствие `[НЕ ВЫПОЛНЕНО]` в выводе) |
| `pageId` | UUID текущей страницы (`PlayerEngine::screen().pageId`) |
| `screen` | `page`, `choices` (открыт экран вариантов), `message` (сообщение: конец игры, внешняя игра, ошибка), `finished` |
| `portion.index`, `portion.count` | номер показанной порции текста VN (с 0) и число порций; вне режима экрана вариантов (STANDARD, варианты в тексте) `count` = 0 |
| `portion.more` | после показанной есть ещё порции |
| `portion.visible` | текст показанной порции: абзацы `{runs: [{kind, text, target}], joinPrevious}` |
| `variables` | `{имя: значение}` из `--state-vars`: число, логическое, строка или `null` |
| `model` | `ScreenModel` целиком (`nlb/presentation/ScreenModelJson.h`): `pageText`, `reactionText`, `choices` (`index`, `text`, `enabled`, `trivial`, `inlineLink`, `altText`), `inventory`, `sceneObjects`, `pageImage`, `style`, `finished`… |

Текст в снимке — исходный текст книги: `--` и прямые кавычки, как в книге. На экране (и в
INSTEAD — модули `dash` и `quotes` экспорта) они показываются как «—» и «ёлочки»; при сравнении
с INSTEAD это нормализация, а не расхождение.

## Команда `settle:<мс>`

`wait:<мс>` после ожидания обновляет сессию (`Session::refresh`, `GameScreen::afterCommand`) — это
закрывает открытый экран вариантов. `settle:<мс>` ждёт так же (анимации идут по часам), но без
обновления: им можно дать кадру успокоиться между действием и `shot:`, не меняя состояния.
