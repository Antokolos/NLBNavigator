# Озвучка текста страницы по фразам

Как в NLBB (экспорт в INSTEAD: `nlb:push` / `nextsnd` / `sndout`), но **в естественном порядке**.

**Как задать.** В поле звука страницы — несколько файлов через `;`:
`voice1.ogg;voice2.ogg;voice3.ogg`, и звук страницы — SFX (флаг SFX у страницы или флаг `.flag`
у файла). Порции текста — как в экспорте VN-INSTEAD: каждая строка текста страницы — порция,
длинная строка (больше 100 символов) делится по предложениям (порция — предложения, пока их не
больше 100 символов; хвост до 330 символов присоединяется к последней). Проще всего — одна фраза
озвучки на строку текста.

**Как играет.**
- На каждой новой порции текста VN (пробел, щелчок) — следующий файл по порядку поля: первая
  порция — `voice1`, вторая — `voice2`… Новая фраза обрывает прежнюю.
- Ответ на действие на той же странице — тоже порции, и они продолжают очередь.
- Без порций (стандартная тема, VN с вариантами в окне текста) — звучит только первый файл, при
  входе на страницу (как `snd` -> `nextsnd` без пагинатора).
- Уход со страницы — звучащая фраза останавливается.
- Не-SFX файлы поля — музыка, `VOID` — тишина, условия (`.constrid`) — как прежде.
- Звуки объектов (SFX) играют сразу, как `add_sound`, — в очередь не попадают.

**Отличие от NLBB.** В NLBB очередь — стек (`nlb:push` кладёт в голову, `nlb:pop` берёт оттуда
же), и файлы звучали с конца поля. Здесь — с начала.
