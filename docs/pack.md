# Пакет книги (.nlbpack) и настройки экспорта (nlb.json)

```
nlb_main <каталог книги> pack <файл.nlbpack> --with-media [--theme <тема>] [--base-theme <тема>]
         [--png2jpg | --no-png2jpg] [--quality 1..100] [--config nlb.json]
```

Упаковка показывает прогресс (`[ 37%] 678/1832 images/…`) и итог конвертации картинок.

## PNG -> JPG

Как экспорт NLBB: картинки PNG книги (каталоги `images/` книги и модулей) при упаковке
перекодируются в JPG — оптимизированные PNG почти не сжимаются ZIP-ом, а JPG в разы меньше.
Что делать с картинкой, решает её пресет экспорта — файл `<картинка>.preset` рядом с ней (его
пишет редактор NLBB):

| пресет | что делается |
|---|---|
| `DEFAULT` (нет файла) | JPG, если `convertpng2jpg` в nlb.json (или `--png2jpg`), качество `quality` |
| `COMPRESSED` | JPG всегда, качество 80; прозрачное — на пурпурном фоне (как NLBB) |
| `NOCHANGE` | остаётся PNG |

Отличия от NLBB, чтобы ничего не испортить:
- картинка с прозрачностью (спрайт) при пресете `DEFAULT` остаётся PNG — NLBB залил бы
  прозрачное пурпурным;
- если JPG получился не меньше PNG — тоже остаётся PNG.

Имя картинки в пакете остаётся прежним (`x.png`), а данные — JPG: страницы, объекты, условия
(`.constrid`) и переадресации (`.redirect`) медиа ссылаются на прежнее имя, и всё работает как
раньше. Формат проигрыватели определяют по содержимому файла. Картинки тем (`--theme`,
`--base-theme`) не конвертируются. Фоновые картинки страниц (BG, «картинка — фон»)
конвертируются, как все, и по-прежнему заменяют фон темы.

## nlb.json

Настройки экспорта — аналог раздела `<export>` config.xml NLBB (пример — `nlb.json` в корне
репозитория). Ищется в текущем каталоге, затем рядом с программой; свой — `--config <файл>`.
Без файла — те же значения, что в NLBB.

- `convertpng2jpg`, `quality` — PNG -> JPG при упаковке (пресет `DEFAULT`);
- `texts` — тексты по умолчанию для языка книги (нет языка — английские): «Хм... Странная
  штука...» при осмотре предмета без описания, «Не сработает...» при неудачном применении;
- `needs-action-count` — как в экспорте INSTEAD;
- `game-forcedsc`, `game-act` — читаются для совместимости с config.xml.
