# Язык игры

**Какой язык включается.** Книга NLB может содержать тексты на нескольких языках. При запуске
плеер включает первый подходящий из списка:

1. выбор игрока в меню «Язык» (запоминается в каталоге сохранений, `settings.ini`);
2. язык лаунчера: Steam (язык игры в клиенте Steam), Epic Games Store (`-epiclocale=…`);
3. ключ запуска: `--lang ru`, `-lang=ru`, `-culture=ru`;
4. язык системы;
5. английский, если его нет — язык книги по умолчанию.

Язык считается подходящим, если тексты книги на нём есть; регион не важен (`ru_RU` = `ru`).

**Меню «Язык»** появляется, когда в книге больше одного языка; языки названы на них самих
(English, Русский…). Смена языка сразу перерисовывает сцену.

**Интерфейс плеера** (меню, сообщения, подсказки) переведён на русский и английский; при других
языках книги он английский. Новый язык интерфейса — ещё один столбец в
`Source/NLBPresentation/Private/nlb/presentation/Localization.cpp`.

**Godot:** свойство `language` у `NLBPlayer` задаёт язык игры по умолчанию (главнее языка системы,
но не выбора игрока в меню).

**Где берутся языки системы:** nlb_sdl — `SDL_GetPreferredLocales`; Unreal — культура Unreal
(учитывает `-culture`) и `FPlatformMisc::GetDefaultLanguage`; Godot — `OS.get_locale_language`.
Язык Steam в Unreal: OnlineSubsystem его не сообщает, поэтому там — язык системы (Steam обычно
совпадает); при необходимости можно добавить запрос к Steamworks.
