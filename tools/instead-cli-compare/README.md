# Безоконная сверка NLBNavigator ↔ INSTEAD через instead-cli

Семантическая сверка без окна, Xvfb и координат: один сценарий проигрывается в плеере и в
настоящем INSTEAD (консольный `instead-cli`), после каждого шага сравниваются переменные.
Так были сверены полное прохождение «Слуги Ра» (222 шага), карточный бой Frontier и
синтетическая книга. Файлы восстановлены по переписке; что проверено заново — см. ниже.

## Состав

| Файл | Назначение |
|---|---|
| `setup_instead_cli.sh` | Сборка `instead-cli` (instead-hub) с Lua 5.1, установка `tiny2.lua` с заглушками |
| `tiny2_append.lua` | Заглушки графического API INSTEAD (спрайты, шрифты, тема, таймер) |
| `tiny2_vn_append.lua` | Дополнительные заглушки для VN-экспортов (vn.lua); дописываются вручную |
| `make_overlay.sh` | Копия экспорта со служебными командами (исходный экспорт не меняется) |
| `instead_main_append.lua` | Команды `/click`, `/var`, `/actid`, `/invid`, `/useid`, `/nlbgo`, `/nlbhere`, `nlbnoop` |
| `cmpwalk_sdl.py` | **Основная сверка**: сценарий по подписям в `nlb_sdl` (без окна, `--state-log`) и в INSTEAD, после каждого шага — страница и переменные |
| `instead_rnd_append.lua` | Общая детерминированная случайность, `/rndlog`, `/rndstart N` (пара к `--deterministic`) |
| `log2script.py` | Лог консольного плеера (номера) → сценарий по подписям |
| `cmpwalk2.py` | Старая сверка («Слуга Ра»): нужен отладочный драйвер `drive`, которого нет (см. ниже) |
| `cmpwalk3.py` | Старая сверка для любой книги: тоже через `drive` |

## Порядок

1. `./setup_instead_cli.sh ~/instead-cli-build` (нужны `liblua5.1-0-dev`, `pkg-config`, `make`, `gcc`).
2. `./make_overlay.sh <экспорт> <копия> [rnd]`.
3. Запуск: `cd ~/instead-cli-build/instead-cli/release && ./instead-cli -e -w1000 <копия>`.
   Команды со стандартного ввода: номер ссылки, `/look`, `/inv`, `user_timer` (тик таймера, 200 мс),
   служебные `/var a b`, `/actid <uuid>`, `/invid <uuid>`, `/useid <uuid> <uuid>`, `/click <имя>`,
   `nlbnoop` (печатает пути с номерами для следующей команды), `/quit`.
   `/nlbhere` печатает текущую комнату (`v_<uuid страницы с _>`).
4. Сверка:
   ```
   python3 cmpwalk_sdl.py --player build/nlb_sdl --book <каталог книги> --game <копия> \
       --cli ~/instead-cli-build/instead-cli/release --script <сценарий> \
       --vars life,energy,courage [--mode standard] [--lang ru] [--out cmpwalk-out]
   ```
   `nlb_sdl` запускается с `SDL_VIDEODRIVER=offscreen` (Xvfb не нужен) и изолированным `HOME`
   (иначе язык и сохранения возьмутся из `~/.nlbnavigator`). Из модели экрана в state-log до
   команды берутся id объектов для `/actid`, `/invid`, `/useid`; номер ссылки в INSTEAD ищется по
   её тексту. В каталоге `--out` остаются `state-log.jsonl`, `player.out`, `instead.out`. Код
   выхода: 0 — всё совпало, 1 — расхождение или сценарий не дошёл до конца.

Сценарий по подписям — команды `nlb_sdl --script`: `c:текст ссылки`, `o:объект`, `i:предмет`,
`u:предмет>цель` (подпись сравнивается по началу, берётся первая подходящая). `log2script.py`
пишет ещё `l`, `w` и номер одинаковой подписи (`кран#2`) — их `nlb_sdl` не понимает, такие строки
нужно убрать или переписать.

## Чего здесь нет

- **Отладочный драйвер плеера `drive.cpp`** не восстановлен. `cmpwalk2.py` и `cmpwalk3.py` ждут от него
  строки `TRACE act|inv|use <id>`, `>>> команда`, `STATE <значения> page=<id>`; без него они не
  работают. Их заменяет `cmpwalk_sdl.py` на `nlb_sdl --script --state-log --state-vars`
  (docs/state-log.md): `--deterministic` у `nlb_sdl` нет (он есть только у `nlb_main`), поэтому книги с
  RND/SHUFFLE этой сверкой пока не проверить — нужен ключ в `nlb_sdl` (задача для Claude Code).
- **Сценарии боя Frontier (`cmpfight.py`)** не восстановлены: они привязаны к конкретному пути до боя.

## Что проверено при восстановлении (10.11.2026, Claude Fable)

- Синтаксис Lua (luac 5.1) и Python — без ошибок.
- `setup_instead_cli.sh` собирает `instead-cli` на Ubuntu 24.04.
- Экспорт wolfman (`instead-am_i_a_monster_vn`, 0db8d2c6) с обоими наборами заглушек загружается и
  принимает команды, но это **VN-экспорт**: текст и выборы рисуются спрайтами и в консоль не выводятся,
  переменные книги появляются после выбора языка. Для wolfman нужны новые служебные команды
  (выбор языка, листание пагинатора, выбор варианта) — они не написаны.
- Сами сверки («Слуга Ра», Frontier) заново не прогонялись: нет драйвера и экспортов этих книг.

## Проверка 10.11.2026 (Claude Code, Linux, main 8a7c6ad)

- `setup_instead_cli.sh` собирает `instead-cli` (ошибка `make install` метапарсера ожидаема).
- `make_overlay.sh` падал, если родительского каталога копии нет, — исправлено (`mkdir -p`).
- Экспорт «Слуги Ра» (`instead-servant-of-ra`): команды `nlbnoop`, `/var`, `/actid`, `/nlbhere`
  работают; `/nlbhere` даёт ту же страницу, что `pageId` плеера.
- `cmpwalk_sdl.py`, «Слуга Ра», 38 шагов (холл, три комнаты с кнопками, кровать, трижды круг с
  убыванием энергии и бодрости): страница и `life`, `energy`, `courage` совпали на всех шагах, прогон
  2,5 с. Обратная проверка: в копии экспорта убыль энергии 4 заменена на 5 — сверка показала
  расхождение с 3-го шага и вернула код 1.
- `/click`, `/invid`, `/useid`, `/nlbgo`, `instead_rnd_append.lua`, `log2script.py` заново не
  проверялись; VN-экспорты (wolfman) — не поддерживаются (см. выше).
